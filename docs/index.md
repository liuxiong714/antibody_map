# 抗体地图 (Antibody Map)

血清抗体流行病学数据管理与分析平台。

[![GitHub](https://img.shields.io/badge/GitHub-liuxiong714/antibody_map-blue)](https://github.com/liuxiong714/antibody_map)

## 概述

抗体地图是一个面向公共卫生和流行病学领域的**血清抗体水平数据管理、可视化与分析平台**。系统支持上传流行病学相关的 PDF 文献，通过 LLM 自动提取结构化的血清抗体数据点，经过人工审核后在交互式中国地图上可视化展示，并支持多维度数据分析和 AI 报告生成。

## 支持的疾病

系统内置疾病别名映射系统（DISEASE_MAP，60+ 映射条目），覆盖各**法定传染病及常见血清流行病学病种**，包括但不限于：

麻疹、腮腺炎、风疹、百日咳、白喉、破伤风、乙肝、甲肝、丙肝、丁肝、戊肝、脊髓灰质炎、流感、新冠、流行性脑脊髓膜炎（含 A/C/Y/W135 血清群）、水痘、手足口病、轮状病毒、肾综合征出血热、登革热、寨卡病毒、黄热病毒、乙脑、肺炎支原体、布鲁氏菌病、森林脑炎、口蹄疫、肺炎、腺病毒感染、莱姆病、发热伴血小板减少综合征（SFTS）、斑点热、虫媒病毒、呼吸道感染、病毒性肝炎、结核（含肺/淋巴结/潜伏/骨等亚型合并）、弓形虫、疟疾、血吸虫、华支睾吸虫、蛔虫、钩虫、丝虫、包虫、囊虫等。

数据库默认种子（`init_db.sql`）包含 **11 种疫苗可预防疾病**（麻疹、腮腺炎、风疹、百日咳、白喉、破伤风、乙肝、甲肝、脊灰、流感、新冠），其余疾病可通过系统内置的疾病管理字典表动态扩展，无需修改代码。

**疾病名称自动标准化**：自动合并同一疾病的不同名称（如乙型病毒性肝炎 → 乙肝、麻腮风/MMR → 麻疹等）。

## 支持的文件格式

PDF、CAJ、EPUB、DOCX、PPTX、XLSX、TXT、HTML。解析采用**策略模式**：各格式独立解析器 + 统一注册表分发。PDF 可选 **MinerU 增强解析**（GPU 加速）或 **AnyDoc 增强解析**（firecrawl/anydoc，Rust 实现，毫秒级转 GFM Markdown），失败自动回退现有解析链。

## 智能特性

- **疾病名称标准化**：60+ 疾病别名映射，一键规范化历史数据（含血清群/亚型自动合并：脑膜炎奈瑟菌 A/C/Y/W135 → 流脑，肺/淋巴/潜伏/骨结核 → 结核病等）
- **提取模式安全**：强制 append 模式禁用 replace，API 层拦截 clear_existing_data=True，防止误删已有数据点
- **提取历史一致性审计**：管理员一键扫描 extraction_history 声明的数据点数 vs data_point 实际行数，自动标记 `[DP_DROPPED]` 并修正
- **文献批量选中与编组**：TXT/CSV 导入匹配（UUID 精确 + 标题-作者模糊匹配），批量打 Tag 分组
- **文献重复检测**：DOI、标题、作者、PDF 哈希多维度自动检测
- **文件夹自动监控**：配置后自动监测新文件并导入提取
- **扫描件 OCR 兜底**：Tesseract OCR（中文+英文）+ 百度 OCR 云端回退
- **知识图谱**：13 种实体类型和 18 种关系类型的多维语义网络，支持计算式推导与 LLM 抽取（含定向抽取），ECharts 力导向图交互式可视化，并提供智能咨询问答
- **交互式溯源查看**：点击数据点可查看原文上下文并高亮定位字符区间
- **元数据自动聚合**：AI 提取完成后自动从数据点聚合年份和省份信息
- **多格式导入导出与跨电脑迁移**：JSON 格式完整包含数据点，可跨电脑迁移
- **纯函数统计引擎**：全局置信区间（CI）引擎统一计算，全部配套单元测试
- **数据驱动常量表**：标准人口、省份邻接矩阵、疾病解读注释等存于 `reference_data/*.json`
- **流行特征模块**：流行病学指标（发病率/发病人数/死亡率/死亡数）聚合展示 + 独立病原学监测表（流行株基因型/血清型/谱系/变异位点），与血清抗体数据互补
- **多域数据扩展**：单一 data_point Schema 覆盖 immunology/epidemiology/pathogen 三大数据域，病原学字段与 disease 解耦，extra JSONB 兜底非常规维度
- **数据点溯源**：`model_used` + `extraction_history_id` 让每条数据点可反查产出模型与批次来源
